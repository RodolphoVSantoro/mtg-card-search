# Mtg Card search

Client to search magic the gathering cards using logic filters

## Resources used

- GUI library: [clay](https://github.com/nicbarker/clay)
- Json library: [jansson](https://github.com/akheron/jansson)
- Server to search cards: [mtg-sql-rs](https://github.com/RodolphoVSantoro/mtg-sql-rs)
